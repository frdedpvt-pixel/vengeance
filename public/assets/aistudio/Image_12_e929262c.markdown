# Design System

## Brand & Style
The design system adopts a modern, fidelity-driven corporate aesthetic utilizing the **Inter** typography family for all headline, body, and label text. The default color mode is set to **dark**, creating a sleek, high-contrast digital environment centered around a vibrant electric blue primary theme (`#0012ff`) and a deep black secondary tone (`#000000`).

## Colors
- **Primary:** `#0012ff` (Electric Blue)
- **Secondary:** `#000000` (Deep Black)
- **Mode:** Dark

## Typography
- **Font Family:** Inter (applied across headlines, body, and labels)

## Layout & Spacing
- **Spacing Scale:** Standardized spacing with 1rem gutters and 1.5rem margins.

## Elevation & Depth
- **Style:** Tonal layering and subtle contrast tailored for dark mode environments.

## Shapes
- **Roundedness:** Level 2 (0.5rem base roundedness for standard UI elements).

## Components
- Styled consistently with dark mode surfaces, rounded corners, and electric blue primary highlights.
